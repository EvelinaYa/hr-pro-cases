# HR Pro — «Кейсы и отзывы»

Вёрстка страницы «Кейсы внедрения КЭДО и истории клиентов» по макету в Figma (HR-Pro, фрейм `7117:16283`) и ui-kit (`383:4414`).

Чистые HTML/CSS/JS без сборки: открыть `index.html` или GitHub Pages.

## Варианты карточек

В правом нижнем углу — панель «Варианты карточек»:

- **Кейсы** 1–4 — карточки из ui-kit `Card 1`…`Card 4`;
- **Отзывы** «Читать 1–3» — `Отзывы читать 1`…`3`; «Видео» — `Отзывы смотреть`.
- **Бизнес-эффекты** 1–2 — `Бизес-эффект 1` и `Бизес-эффект 2` (светлые плашки или тёмная вуаль).

«Читать далее» в карточке отзыва открывает полный отзыв в модальном окне (закрывается по клику на фон или Esc). Ссылка вида `?review=2#review-1` открывает страницу сразу с окном.

Вкладки «Читать отзывы / Смотреть отзывы» на странице связаны с панелью. Выбор записывается в адрес (`?case=3&review=2&effect=2`), так что ссылку на нужную комбинацию можно отправить.

## Структура

- `index.html` — разметка;
- `css/style.css` — стили, токены цветов из ui-kit в `:root`;
- `js/main.js` — данные и шаблоны карточек, переключатель вариантов, вкладки, теги, модальное окно отзыва и проверка формы (отправки на сервер пока нет — после проверки показывается «Спасибо»);
- `img/` — ассеты, выгруженные из Figma.
